원본 파일 및 의미
================
기존 grasp_workspace.csv: 1403개, 원래 base_footprint 프레임의 TCP 파지 중심. 베이스 후보 위치가 아님.
기존 analyze_workspace.py는 check_grasp() 전체 경로 통과 행만 이 CSV에 저장. 따라서 전부 초록색: IK + FCL 접근/하강/닫기/인양 경로 통과. 물리 파지 성공을 뜻하지 않음.
정책: 수직 +90도 tool pitch, 접근/인양 각 60mm, 30mm 구형 물체 폭 근사, 바닥 여유 3mm, 추가 자기 충돌 여유 0mm.
실패한 격자점 좌표나 IK 통과/FCL 실패 행은 저장되지 않았으므로 추가 생성하지 않음.
별도 reachable_workspace.csv 32768행은 FK 관절 샘플. 이 시각화의 1403개와 다른 자료이므로 섞지 않음.

좌표 정렬
link1 = base_footprint + (0.092, 0, -0.101)m. 저장된 실제 TF 행렬 그대로 사용.
3D, Top XY, Side XZ 모두 같은 1403개 점, 같은 link1 프레임, 단위 m.
로봇 모델은 원본 URDF/USD와 저장된 2026-10-29 관절 자세로 표시. 새 FK 점 샘플링이나 IK 계산 없음.

실제 바나나
관측 시각: 2026-10-29T21:13:14.097574+09:00
동일한 한 장의 RGB-D에서 나온 후보 9개만 사용. 당시 팔 관절과 camera->link5->link1 변환은 원본 capture.json/npz에 보존.
속이 빈 빨간 원: 관측 표면 observed_link1. 빨간 마름모: 기존 X +30mm 적용 target_link1, 저장된 실제 C++ IK 평가 목표.
9개 모두 저장된 평가에서 IK 실패. FCL을 통과했다고 표시하지 않음.
최근접 점 거리: 0.1529~0.1818m. 단, 최근접 거리나 점군 외곽은 연속 도달 범위 판정 기준이 아님.
점군은 수직 접근, 바나나 기록은 native -80~-15도 접근 평가여서 자세 조건 차이가 있음. 실제 실패 표시는 저장된 native 결과를 사용.

색상 변경 주의
이전 5개 시뮬레이션 후보 그림: 노랑 = IK/FCL 통과·물리 미검증, 빨강 = IK/FCL 실패.
이번 연구 분석 범례: 초록 = 저장된 IK+FCL 전체 경로 통과(기하학), 노랑 = IK 성공/FCL 실패, 빨강 = IK 실패.
원본 1403개에 노랑/빨강 행은 없으며 임의로 만들지 않음. 이번 빨강은 기존 실측 바나나 9개만 의미.

새 로봇/카메라 실행, 물리 시험, 제어 코드 변경, 새 IK/충돌 계산, 무작위 샘플링 없음.
